# Memory

## Project Overview
- **Repository**: Prince Club (`ETechnoviax-Tech/prince-club`)
- **Stack**: React 18, Vite, Lucide React, CSS
- **Purpose**: Practice color prediction and trading simulator with virtual balance

## Architecture & Conventions
- `src/App.jsx`: Core application logic, game timers, wallet balance, betting rounds
- `src/styles.css`: Complete styling and design system
- `src/main.jsx`: Vite React root mounting
- Build command: `npm run build` (`vite build`)
- Dev command: `npm run dev`
