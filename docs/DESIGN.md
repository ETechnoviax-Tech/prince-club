# UI / UX Design Specifications - 69 Club

## Aesthetic & Design System
- **Theme**: Clean crisp white light theme with vivid coral/red accents matching authentic 55 CLUB standard.
- **Viewport**: Centered mobile viewport canvas (max-width: 430px) with desktop backdrop (`#f1f3f7`).
- **Primary Brand Gradient**: `linear-gradient(90deg, #ff6054 0%, #f2413b 50%, #e62c25 100%)`.
- **Card Surfaces**: Pure white (`#ffffff`) with subtle drop shadows (`0 4px 16px rgba(0,0,0,0.06)`).
- **Typography**: Inter / Outfit / Sans-serif system stack with high-contrast text tokens (`#1f2937` primary, `#6b7280` secondary).

## Interactive Components
- **Top Header**: Crown branding, download cloud pill, scrolling marquee banner.
- **Wallet Action Row**: Total balance counter, orange Withdraw and coral Deposit pills.
- **5-Tab Navigation**: Lobby, Activity, Spinning Wheel (elevated center ₹500 badge), Promotion, Account.
- **Modal Dialogs**: Bottom-sheet drawers and centered dialogs for Auth, Deposit QR, Withdrawals, VIP Bonus, and Game Rule details.
